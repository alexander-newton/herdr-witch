⛧ herdr-witch: v6

v6: the sigil pane takes 15% of the tab's width (try other sizes with the slider), drawn at the true pixel count for a terminal that wide (set yours with the slider). Below about 34 sigil pixels the runes turn into dots and a 9-pixel mini witch takes over. herdr keeps its default colours; only the sigil, the witch and the grimoire text carry the theme. The grimoire is one line in a 1.5-line pane at curse level 4, and the sigil pane hugs the animation's width.
Drag agents working to see the sigil go from embers to gold to cyan lightning. Type in the agent pane's prompt and the witch raises her arms. Switch tabs: each has its own grimoire line, and the sigil shows the same state in every tab. Click × to close a pane on one tab only.

sigil pixels:
Honest resolution: the sigil is drawn at true terminal resolution. Each pixel is half a character cell (▀ half-blocks), so a 44-column pane gives a 44×44 sigil, animated at about 12 fps like the real thing would be. Kitty graphics could go sharper, but that depends on your outer terminal.
Diacritics: real terminals cap how many combining marks they stack per cell, and the marks overlap neighbouring rows. How cursed it looks will depend on herdr's renderer, so the mockup gives the text more line spacing than a terminal would.
Glow: the soft blur in v1 was CSS. A terminal can't blur, so the grimoire here glows the way it would for real: by cycling colours word by word (gold → bright gold → cyan, with violet dips). Tick the checkbox to compare it with the browser-only version.
1.5 lines: a terminal pane is a whole number of rows tall. The real pane would give the text one row, and its border supplies the rest. The diacritics spill over that row as far as herdr's renderer allows.
Text: sample lines after Mathers' Goetia (1904, public domain). The real version would draw verbatim passages from a public-domain grimoire.
